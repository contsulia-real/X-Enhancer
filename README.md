# 𝕏 Enhancer

为 X（x.com）增加本地浏览历史、回复筛选和侧栏整理功能。支持简体中文、繁体中文、日语、韩语、英语、法语；界面语言跟随 X 的显示语言。

## 功能

- 浏览历史：记录打开过的帖子，按当前账号隔离，支持搜索、逐条删除和清空。
- 回复筛选：全部回复、只看原作者、只看蓝V；可隐藏戏仿账号。关注账号的回复通过 X 搜索查看。
- 推荐算法信息：侧栏显示规则、权重与更新记录，支持完整／精简视图。
- 隐藏侧栏中的直播和体育赛事卡片。

## 安装

1. 从 [Releases](../../releases) 下载 `X-Enhancer-v0.1.0.zip` 并解压。
2. 打开 Chrome 的 `chrome://extensions`，启用**开发者模式**。
3. 点击**加载已解压的扩展程序**，选择解压后包含 `manifest.json` 的文件夹。
4. 打开或刷新 `https://x.com`。

GitHub Releases 安装的扩展不会自动更新；新版本需自行下载并替换。扩展没有 Chrome Web Store 发布版本。

隐私和本地数据存储说明见 [PRIVACY.md](PRIVACY.md)。

## English

𝕏 Enhancer adds local post history, reply filters, and sidebar customization to X (x.com).

Features: searchable per-account browsing history; original-author and blue-check reply filters; hide parody replies; recommendation-algorithm summaries with full/compact views; hide Live and sports-score sidebar cards. UI languages follow X: Simplified Chinese, Traditional Chinese, Japanese, Korean, English, and French.

**Install:** Download and extract `X-Enhancer-v0.1.0.zip` from [Releases](../../releases). Open `chrome://extensions`, enable **Developer mode**, choose **Load unpacked**, then select the extracted folder containing `manifest.json`. Refresh X.

GitHub-installed extensions require manual updates. Read [PRIVACY.md](PRIVACY.md) for data handling details.
